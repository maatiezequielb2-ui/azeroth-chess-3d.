# Esculturas originales: prototipo

12 mallas GLB con materiales embebidos, construidas localmente mediante Blender. No incluyen modelos descargados ni datos de juegos de Blizzard.

Reproducir: `blender --background --python tools/build_models.py -- --preview`.

Los seis humanoides tienen un esqueleto de siete huesos y animaciones idle, walk y attack. La app utiliza caminar y golpear para ambos peones.

La fidelidad visual todavía está por debajo de la propuesta conceptual aprobada. Los PNG preview son renders de las mallas GLB correspondientes.
